# Ideate (Product Design)

1. **Explore Visual Concepts**:
   - Brainstorm 2-3 distinct visual themes (e.g., sleek dark mode with glassmorphism, high-contrast vibrant dashboard, modern minimalist).
   - Define color tokens, typography scales, and structural layouts for each option.

2. **Generate Mockups**:
   - Use image generation or Figma design tools to visualize key screens.
   - Present options to the user with pros/cons for each layout direction.
