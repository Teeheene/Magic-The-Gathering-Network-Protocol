# Get Context (Product Design)

Before writing any frontend code or component implementation:

1. **Screen Definition**:
   - Identify the primary goal of the view or screen.
   - Map out the primary user/player personas and their objectives.

2. **Action Mapping**:
   - List all available user/player actions on this screen.
   - Categorize actions into primary (high frequency/importance) and secondary actions.

3. **Information Hierarchy**:
   - Define focal points and reading flow (Z-pattern or F-pattern).
   - Determine which data elements require real-time emphasis vs supporting detail.
   - Establish card/container groupings and spatial relationships.
