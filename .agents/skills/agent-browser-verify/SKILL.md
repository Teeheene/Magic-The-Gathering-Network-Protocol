# Agent Browser Verify

1. **Browser Subagent Execution**:
   - Launch browser agent to open local development URL (e.g. http://localhost:3000).
   - Perform user interactions: clicks, text inputs, tab navigation, drag-and-drop.

2. **Automated Auditing**:
   - Inspect console logs for Javascript exceptions or unhandled rejections.
   - Verify layout responsiveness and visual rendering.
