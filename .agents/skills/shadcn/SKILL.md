# Shadcn UI

1. **Component Architecture**:
   - Utilize standard Accessible primitives for dialogs, dropdowns, tabs, modals, popovers, tooltips, and navigation.
   - Maintain consistent variants and sizes across buttons, inputs, cards, and badges.

2. **Styling & Design System**:
   - Use CSS variables / design tokens for theme switching (light/dark mode).
   - Ensure full keyboard accessibility and screen reader support.
